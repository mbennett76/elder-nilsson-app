# Elder Nilsson's Paraguay Mission App 🇵🇾

**Paraguay Ascensión Norte Mission | Spanish | MTC: September 23, 2026**

A language learning and mission prep app for Elder Sam Nilsson.

## Setup

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

```bash
git add .
git commit -m "Deploy Elder Nilsson Paraguay Mission App"
git push
npm run deploy
```

Live at: https://mbennett76.github.io/elder-nilsson-app

## Features

- 🕐 Live countdown to MTC date
- 🔥 Daily streak tracker
- 🔤 Spanish alphabet with audio (Ñ included)
- 💬 Mission phrases in 4 categories
- 🇵🇾 Paraguay culture guide
- 📖 Parallel Spanish/English reader
- 📚 Vocabulary flashcards & quiz (9 categories)
- 🎙️ Speaking exercises with recording
- 📜 LDS Scriptures in Spanish & English
- 🤖 AI conversation with Paraguayan investigators

## Tech

React + Vite, Web Speech API, Anthropic API (user-supplied key), localStorage
